# CHAIR — Product & Engineering Roadmap

Each phase is a self-contained vertical slice gated by migrations, lint, typechecks, and automated unit/integration tests before moving forward.

| Phase | Name | Primary Deliverables | Exit Gate |
| --- | --- | --- | --- |
| **0** | **Foundation** *(Done)* | Monorepo (`apps/api`, `apps/mobile`, `apps/web`, `packages/shared-types`), `docker-compose.yml`, `.env.example`, all 33+ SQLAlchemy/GeoAlchemy2 models + initial Alembic migration (`btree_gist` + PostGIS), `/api/v1/health`, `[DEMO]` seed script, domain invariants (`booking_states`, `hygiene`), unit + concurrency test scaffolding | `ruff`, `mypy`, `pytest` pass; workspace `typecheck`/`lint` pass; live `alembic upgrade head` & concurrency DB tests pass |
| **1** | **Auth, RBAC & Consents** *(Done)* | Phone OTP adapters, JWT access/refresh tokens with atomic Redis Lua rotation, RBAC & branch tenant guards, DPDP `user_consents` endpoints, audit trail, Customer & Partner/Admin auth UI | Auth/RBAC unit + live Postgres/Redis integration tests & Playwright login flow pass |
| **2** | **Customer Discovery, Availability & Mobile App** *(Done)* | PostGIS radius search & filters (`GET /api/v1/branches`, `/branches/{id}`, `/branches/{id}/availability`), real multi-service slot calculator (shifts, breaks, buffers, walk-ins, holds, pause toggle), featured & `CHAIR VERIFIED` disclosures, `apps/mobile` Expo Router tabs (`Explore`, `Branch Detail & Slot Picker`, `Account`), EN/HI parity | Availability unit/property tests + live PostGIS integration tests + mobile unit tests + Expo Web viewport E2E verification pass |

| **5** | **Payments, Ledger & Notifications** | Pay-at-salon + Razorpay test-mode adapter, signature-verified idempotent webhooks, late-payment auto-refund protection, commission ledger, subscriptions, FCM/SMS/email adapters | Webhook replay, expired-hold refund, and commission accrual tests pass |
| **6** | **Trust, Inspections, Style Passport & Polish** | Physical hygiene checklist with critical failure override, admin verification/suspension/disputes/audit UI, completed-only reviews, private Style Passport photos, Hindi `hi` parity, full E2E + budget-Android perf/a11y audit | Full Playwright E2E + Android emulator/RN Web responsive & accessibility audit pass |
